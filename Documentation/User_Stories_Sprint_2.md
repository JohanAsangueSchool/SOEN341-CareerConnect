During Sprint 2, the team will complete the following features:
- User Profile and Resume Management   
- Job Search and Job Listing Interface  
- Job Application Submission and Tracking

The team will start implementing Recruiter Dashboard and Posting Management. The team will also prepare acceptance tests.

US-01: User Profile Management (Continued from Sprint 1)  
- As a job seeker, I want to create and update my profile so that recruiters can learn about my education, occupation, and city of residence.
- Scope: Verify profile creating, editing, and display.

US-02: Resume Management (Continued from Sprint 1)  
- As a job seeker, I want to upload and manage my resume so that when applying for jobs, I can use the resume in my account directly.  
- Scope: Verify resume uploading, replacing, and display.

US-03: Job Search and Job Listing Interface (Continued from Sprint 1)  
- As a job seeker, I want to search and filter job postings by keywords, location, and job type so that I can find relevant job opportunities efficiently.  
- Scope: Display available job opportunities, and provide search and filtering capabilities.

US-16: View Job Details  
- As a job seeker, I want to view detailed job descriptions so that I can better understand each position and decide whether to apply.  
- Scope: Display detailed job descriptions. 

US-05: Job Application Submission (Continued from Sprint 1)  
- As a job seeker, I want to submit a job application through the platform so that I can apply for positions without managing applications across multiple systems.  
- Scope: Enable job application and provide confirmation of successful application submission.

US-06: Job Application Tracking (Continued from Sprint 1)  
- As a job seeker, I want to track the status of my applications so that I know whether the status is applied, under review, interview, offered, or rejected.  
- Scope: Display application status.

US-08: Recruiter Posting Management (continued from Sprint 1) 
- As a recruiter, I want to create and manage job postings so that I can advertise available positions to job seekers.  
- Scope: Start implementing job postings creation and management, and display applications received for a posting.
