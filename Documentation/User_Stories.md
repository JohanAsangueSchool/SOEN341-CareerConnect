US-01: As a job seeker, I want to create and update my profile so that recruiters can learn about my education, occupation, and city of residence.
US-02: As a job seeker, I want to upload and manage my resume so that when applying for jobs, I can use the resume in my account directly.
US-03: As a job seeker, I want to search and filter job postings by keywords, location, and job type so that I can find relevant job opportunities efficiently. 
US-04: As a job seeker, I want to save interesting job postings so that I can review and apply to them later.
US-05: As a job seeker, I want to submit a job application through the platform so that I can apply for positions without managing applications across multiple systems.
US-06: As a job seeker, I want to track the status of my applications so that I know whether an application is submitted, under review, rejected, or accepted.
US-07: As a job seeker, I want to receive notifications when my application status changes so that I can respond promptly to recruiters.
US-08: As a recruiter, I want to create and manage job postings so that I can advertise available positions to job seekers.
US-09: As a recruiter, I want to view candidate profiles and resumes so that I can identify candidates who match my job requirements.
US-10: As a recruiter, I want to update candidates' application statuses and provide relevant feedback so that candidates can understand their progress in the recruitment process.
US-11: As a job seeker, I want to receive notifications when new jobs in my fields of interest is posted so that I can be an early applicant.
US-12: As a job seeker, I want to receive notifications when saved job postings are about to expire, so that I can apply in time.
US-13: As a job seeker, I want to use the AI tools to generate tailored cover letters so that I can save time when writing a cover letter for each application.
US-14: As a recruiter, I want to search for users based on their fields so that I can find potential candidates.
US-15：As a recruiter, I want to create favorite lists to save specific users so that when relevant job opportunities become available, I can contact them directly on the platform.
Of the user stories listed above, 1-10 were generated by AI and we review and revise them. 11-15 were proposed during a team brainstorm.
