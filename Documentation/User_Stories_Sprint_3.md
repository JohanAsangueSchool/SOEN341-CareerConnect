During Sprint 3, the team will complete the following features:
- Recruiter Dashboard and Posting Management   
- Application Analytics and History Dashboard  
- Notifications and Reminders

The team will start implementing AI-Powered Resume Feedback and AI Job Matching Suggestions. The team will also prepare acceptance tests.

Feature 1: Recruiter Dashboard and Posting Management

US-17: Recruiter Dashboard
- As a recruiter, I want to access a dashboard to view and manage all my job postings so that I can monitor my recruitment activities.
- Scope: Display all job postings, the number of applications received, and the corresponding application details and status.

US-18: Posting Management 
- As a recruiter, I want to create, edit, archive, and manage my job postings from the dashboard so that I can efficiently manage my recruitment activities.
- Scope: Allow recruiters to create, edit, archive, and manage their postings from the dashboard.

US-19: Applications Filter and Candidates Review
- As a recruiter, I want to filter applications by status and submission date so that I can efficiently manage the recruitment process.
- Scope: Allow recruiters to filter applications by status and date.

US-09: Candidates Review (Continued from Sprint 1)
- As a recruiter, I want to view candidate profiles and resumes so that I can identify candidates who match my job requirements.
- Scope: Display candidate profiles and resumes for recruiters to review. 

US-10: Application Status Update (Continued from Sprint 1)
- As a recruiter, I want to update candidates' application statuses and provide relevant feedback so that candidates can understand their progress in the recruitment process.
- Scope: Allow recruiters to update candidates’ application statuses.

Feature 2: Application Analytics and History Dashboard 

US-20: Application History Dashboard
- As a job seeker, I want to view my submitted applications in a dashboard so that I can review my application history.
- Scope： Display application history and a breakdown of application status.

US-21: Application Analytics
- As a job seeker, I want to view my applications submitted over time so that I can understand my job application progress.
- Scope: Display job-search activity metrics such as applications submitted over time.

Feature 3: Notifications and Reminders

US-22: Application Status Update Notifications
- As a job seeker, I want to receive notifications when my application statuses change so that I can keep track of important updates.
- Scope: Generate in-app notification for application status updates and interview invitations.

US-23: Application Deadline Reminders
- As a job seeker, I want to receive reminders about upcoming job application deadlines so that I do not miss opportunities to apply for jobs.
- Scope: Generate in-app reminders for upcoming job application deadlines.

US-24: New Application Notifications
- As a recruiter, I want to receive notifications when candidates submit new applications so that I can review applications promptly.
- Scope： Generate in-app notification for new application submissions.

Feature 4: AI feature

US-25: AI-Powered Resume Feedback
- As a job seeker, I want to receive AI-powered feedback on my resume so that I can identify areas for improvement.
- Scope: Analyze resumes using AI and provide suggestions for improvement.

US-26: AI Job Matching Suggestions
- As a job seeker, I want to receive AI-powered job recommendations based on my profile and resume so that I can find suitable job opportunities。
- Scope: Compare user qualifications with job postings using AI and recommend relevant job opportunities.
